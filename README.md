Echoes of Aethelgard - Text RPG

How to play:
- Run: python3 echoes_of_aethelgard.py
- Choose terminal or browser mode from the launch menu.
- Run terminal mode directly: python3 echoes_of_aethelgard.py --cli
- Run browser mode directly: python3 echoes_of_aethelgard.py --web
- Browser mode also accepts: --host HOST --port PORT --no-browser

Notes:
- Save and load use savegame_slot1.json through savegame_slot3.json in this folder.
- Use 'help' in-game to see commands (including 'examine <item>').
